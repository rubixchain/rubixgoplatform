## What Was Built

### Task 1 — core/wallet/token_chain.go

**PersistGenesisTokenRecord:** After the `tokenchain` INSERT, added a tokenchain_index upsert inside the same `pgx.Tx`. Uses `tx.QueryRow` to SELECT `array_agg(id ORDER BY position)` for the token, then `tx.Exec` to upsert into `tokenchain_index`. Atomic with genesis inserts — rolls back together on failure.

**AddTokenChainEntry:** After the tokenchain INSERT, added the same upsert pattern via `w.db.Pool()` (no transaction — matches the function's existing direct-exec style).

**GetTokenchainIndex(tokenID string) (*models.TokenchainIndex, error):** New read accessor. SELECTs `token_id, index, created_at, updated_at` from `tokenchain_index`. Scans `INTEGER[]` into `[]int32`, converts to `[]int` for `models.TokenchainIndex.Index`. Returns `nil, nil` on `pgx.ErrNoRows`.

### Task 2 — cmd/dev/main.go

**Step C2** (after genesis seeding loop): iterates over the 3 genesis tokens, calls `GetTokenchainIndex`, asserts non-nil and `len(idx.Index) == 1`, prints index.

**Step F6b** (after Step F6 chain position assertions): calls `GetTokenchainIndex("QmTestToken001")`, asserts non-nil and `len(transferIdx.Index) == 2` (genesis + transfer), prints index.

Both use `log.Fatalf` on failure — hard assertions consistent with existing runner style.
